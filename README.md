# نبض (NabdNet)

**نظام ذكي لمراقبة شبكات المستشفيات واكتشاف الأعطال والتنبؤ بها**

مشروع كابستون (Capstone: مشروع التخرج) للصف الثاني، قسم الشبكات، 2026–2027
مدرسة WE للتكنولوجيا التطبيقية (WE Applied Technology School)
**الفريق رقم: 406212**

---

## نبذة عن المشروع

نبض هو نظام برمجي يراقب شبكة المستشفى، ويكتشف المشكلات مبكرًا، ويحلل أسبابها، ويقترح الحل المناسب. لا ينفذ أي إجراء إلا بعد موافقة مهندس IT، ثم يعيد القياس ليتأكد أن المشكلة انتهت.

## المشكلة

عندما تتباطأ شبكة المستشفى يتأخر فتح ملفات المرضى وصور الأشعة. لا يعرف أحد السبب ولا وقت بدايته، ويعلم فريق الـIT بالمشكلة بعد أن يشتكي الموظفون، ثم يشخّصها يدويًا، وهذا يستغرق وقتًا.

## الحل

نظام واحد يجمع:
- مراقبة الشبكة (Monitoring)
- اكتشاف المشكلات وتحليل أسبابها
- التنبؤ بالأعطال قبل حدوثها
- إنذارات بالعربية
- اقتراح الحلول، والتنفيذ بعد موافقة بشرية

وكل ذلك بواجهة عربية سهلة وبدون أجهزة إضافية.

## كيف يعمل النظام

جمع البيانات ← مراقبة الشبكة ← اكتشاف المشكلة ← تحليل السبب ← اقتراح الحل ← موافقة مهندس IT ← تنفيذ الحل ← اختبار الشبكة

يحسب النظام **درجة صحة الشبكة (Health Score)** من 100:
- أخضر: 80 فأكثر (سليمة)
- أصفر: من 50 إلى 79 (تحذير)
- أحمر: أقل من 50 (خطر)

## تحدي الكابستون

يعمل المشروع ضمن **التحدي A: الزحمة والعدالة (Congestion & Fairness)**، أي ألا يستهلك جهاز واحد سرعة الشبكة كلها. المتطلبات الرسمية للتحدي:

| المقياس | الهدف |
|---|---|
| زمن اكتشاف المشكلة (MTTD) | دقيقتان على الأكثر |
| زمن إصلاحها (MTTR) | 10 دقائق على الأكثر |
| حركة الجهاز المتسبب | تنخفض 50% على الأقل |
| دقة الاكتشاف | 4 من 5 حوادث، بدون إنذار كاذب |

## شبكة المستشفى المحاكاة

شبكة مستشفى متوسطة الحجم مصممة على Cisco Packet Tracer (محاكي شبكات من سيسكو)، مقسمة بـVLANs (شبكات افتراضية منفصلة):

| القسم | VLAN | عنوان الشبكة |
|---|---|---|
| الإدارة | 10 | 192.168.10.0/24 |
| الاستقبال والطوارئ | 20 | 192.168.20.0/24 |
| الأشعة | 30 | 192.168.30.0/24 |
| المعامل | 40 | 192.168.40.0/24 |
| العناية المركزة | 50 | 192.168.50.0/24 |
| الصيدلية | 60 | 192.168.60.0/24 |
| السيرفرات | 70 | 192.168.70.0/24 |
| المرضى والزوار | 80 | 192.168.80.0/24 |
| إدارة الشبكة (IT) | 99 | 192.168.99.0/24 |

## الأدوات والتقنيات

**الشبكات:** Cisco Packet Tracer, VLANs, Trunking, Inter-VLAN Routing, DHCP, ACLs, QoS, SNMP, Syslog, SSH, ICMP

**البرمجة والتحليل:** Python, Flask, SQLite, Pandas, Scikit-learn, Chart.js, HTML/CSS/JavaScript, Wireshark, GitHub

## أهداف التنمية المستدامة (SDGs)

- **SDG 3:** الصحة الجيدة والرفاه، بتقليل تأخر الخدمات الطبية
- **SDG 9:** الصناعة والابتكار والبنية التحتية، بتحسين البنية الرقمية للمستشفى
- **SDG 8:** العمل اللائق ونمو الاقتصاد، بتقليل الوقت الضائع وتكاليف توقف الشبكة

## حالة المشروع

المشروع قيد التطوير. النظام يعمل على شبكة محاكاة ببيانات وهمية، ولا يقرأ أي بيانات للمرضى. الربط بشبكات مستشفيات حقيقية ضمن الرؤية المستقبلية.
